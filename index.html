📖 그림책제조기 v1

씨앗 한 톨(단어·주제·사진) → 큐레이터가 해석·논평·영문 프롬프트 집필 → 화가(이미지 모델)가 그린다 → 클릭 한 번으로 Google Drive

🔑 API 키비누제조기와 같은 계정(github.io)이면 자동 공유됨
